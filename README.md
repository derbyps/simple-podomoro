# simple-podomoro

A one-day focus board. Add up to three tasks, run a 25-minute focus block, then a 5-minute break. The list and the countdown stay in this browser after a refresh. When the calendar date changes, the board starts empty again.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).
